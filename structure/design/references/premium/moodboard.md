## Research Brief

**What we are looking for:**

A product detail page, catalog layout, or product card that communicates:
- High visual quality without clutter
- Large, well-composed product photography as the primary element
- Typographic hierarchy that feels editorial (intentional, not generic)
- Whitespace used deliberately to separate and elevate content
- Primary actions that are always reachable, with optional visual sophistication

**We are NOT looking for:**
- Generic luxury templates with gold dividers and serif + script combinations
- Layouts that hide prices or primary CTAs
- Design systems that only work for fashion/apparel — this is tech hardware

## Anti-References — What to Avoid

| Anti-pattern | Description | Why problematic |
|--------------|-------------|----------------|
| Generic luxury template | Gold/rose-gold dividers, script fonts, excessive ornament | Looks cheap despite luxury intent; wrong industry |
| Hidden primary actions | Add-to-cart accessible only on hover, 0 opacity at rest on all devices | Violates WCAG 2.1 SC 2.1.1; bad UX on touch |
| Low-contrast decorative text | Light text on barely-different light background | Fails WCAG AA |
| Magazine-layout complexity | Multi-column editorial layouts with text wrapping around images | Too complex for an e-commerce product grid |
| Price obscured or missing | Price only shown on hover or after interaction | Dark pattern |
| Black-dominant palette | Teenage Engineering / B&O style all-black background | Conflicts with PCShop premium warm neutral direction |
